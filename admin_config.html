🤖 Cấu hình Groq API Key

Key được lưu mã hóa trong Firebase. File HTML không chứa key — người dùng xem source code sẽ không thấy.

📋 Hướng dẫn lấy Groq API Key miễn phí

  1. Truy cập console.groq.com
  2. Đăng nhập tài khoản Google
  3. Nhấn "Create API key"
  4. Sao chép key (bắt đầu bằng gsk_...)
  5. Dán vào ô trên và nhấn Lưu
